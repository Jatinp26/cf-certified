Why build on Canton?

Canton is the public, permissionless blockchain built for regulated finance. It gives institutions the privacy and control they need, and gives builders the composability and open access they expect from a public network.

Real assets, real volume

Applications on Canton already process more than $6 trillion in on-chain assets, including over $280 billion in U.S. Treasury repo every day. This is where tokenized finance is happening at scale.

Privacy built into the protocol

Each party only sees the parts of a transaction they're entitled to see. Positions and counterparties stay private, while the network still guarantees everyone agrees on the outcome.

Composable across the network

Through the Global Synchronizer, apps run by different organisations settle atomically together. A tokenized bond on one app can be collateral on another and paid for with a stablecoin from a third, in one transaction.

Builders get rewarded

Canton's network economics reward the application providers and validators who create real activity. Build something people use, and the network is designed to pay you for it.

Building alongside Goldman Sachs, BNP Paribas, HSBC, Broadridge, Circle and a growing ecosystem of market makers, custodians, wallets and stablecoin issuers.

What is Daml?

Daml is the smart contract language for Canton. If Solidity is how you write contracts for the EVM, Daml is how you write them for Canton. It's built around one question other languages leave to you: who is allowed to do this, and who gets to see it?

  • Signatoriesmust authorize a contract before it exists, so nobody can put obligations on you without your consent.
  • Observerscan see a contract without being bound by it.
  • Controllersdefine exactly who can exercise each choice.

Daml 3 runs on Canton 3.x, the stack behind today's Canton Network. It's what new projects should build on, and the version this certification covers.

Frequently asked questions

How much does it cost?
All courses are free. The certification exam costs $150.
Can I get the exam fee waived?
In some cases, yes. The Canton Foundation issues coupon codes that waive the exam fee, for example through ecosystem programs, events and partner teams.
Which path should I take first?
New to Canton or Daml? Start with Path A: Daml 3 Foundations. Already working with Daml 2? Take Path D: Daml 2 → 3 Upgrade.
Can I skip Path A and go straight to B or C?
Path A is the prerequisite for both. It covers the core concepts everything else depends on, so even experienced blockchain developers should start there.
I'm an Ethereum or Solidity developer. Is this for me?
Yes. Path A assumes no prior Canton experience. Contracts, tokens and transactions will feel familiar, but Canton's privacy and authorization model is different enough that Foundations will save you a lot of time.
What's the difference between Daml 2 and Daml 3?
Daml 3 runs on Canton 3.x, which powers today's Canton Network and Global Synchronizer. Daml 2 targets earlier Canton versions. All new development and this certification track focus on Daml 3.
Are Daml 2 courses still available?
Yes. They stay live for institutions still running Daml 2, but only the Daml 3 track is actively promoted for certification.
When will the Solutions Architect path launch?
Path C and its exam are in development and coming soon.
Are the courses self-paced?
Yes. Every course is online and self-paced, so you can learn around your own schedule.
Where can I get help while learning?
Ask questions in the Canton developer forum and explore the official docs at docs.canton.network.
